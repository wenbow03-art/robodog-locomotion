# 侧移周期0.8秒：旧V8续训200轮

用户已授权目标周期0.8秒、其他不变、训练200轮。源为旧V8最终model200，哈希3480ca2abddfcd62df2be30d89e53a992e3eadc100add59df131213feef48a5a。

任务`lz_q1l_flat_lateral_cycle`。新增环境/配置写在`lz_q1l_2.py`和`lz_q1l_2_config.py`；旧配置文件不改。完整继承旧V8环境、采样概率/速度范围、5ms物理步长/decimation4、4096环境、100步rollout、PPO参数和原奖励。配置差异检查只允许新增周期奖励参数。

同一只脚两次**有效落地**之间目标0.8秒，容差0.1秒；先有稳定支撑，再离地至少0.06秒且碰撞球底离地至少1cm，最后连续0.04秒垂直力≥5N，才计一次有效落地。腾空时力≤1N。第一次有效落地用于建立计时基准，不当作完整周期。每次指令变化或环境重置清除计时。

新增`lateral_cycle=-0.5`，仅纯侧移生效：

- 周期误差：`max(abs(T-0.8)-0.1,0)/0.8`，平方，保持到下一次有效落地。
- 超时误差：`max(距离上次有效落地的时间-0.8-0.1,0)/0.8`，平方。尚未有效迈步的脚从指令开始计时，不能靠不动避罚。
- 每脚取上述较大值，四脚平均，归一化误差封顶2；环境按50Hz控制步长缩放奖励。
- 这项也约束过快步伐；轻触地抖动或不抬脚不能刷新周期。

训练沿用旧V8原生左右采样方式，未改成镜像增强；部署时保留左移镜像右移。训练旧V8独立模型，原站立/直行baseline不进入优化器，不覆盖组合控制器的固定权重。因新baseline在5ms站立曾失败，本次不把5ms直接用于正式新baseline。训练完成后应先评估侧移，再决定部署。
