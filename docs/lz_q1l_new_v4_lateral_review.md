# 新v4：在新baseline上学习侧移（无镜像版本，已授权500轮）

## 继承对象

新baseline是用户确认的**组合控制器**：原gait150负责站立，model800负责直行，右后腿修正量在站立/直行之间按0.3秒变化。不是旧v1/v8，也不是把model800的站立行为直接当作baseline。

归档：`HIMLoco/legged_gym/logs2/baselines/stand_walk800_20261027/`。
包含model800、gait150权重副本、哈希、控制代码快照和已完成的仿真证据。
model800 SHA256：`23d99708723bacb0a5cc5c473a66e76f076a3444a738a1a27c1a9f9d6b937086`。
归档并不宣称原有停车偏载、高速超速或下沉已解决。

新任务：`lz_q1l_flat_v4_lateral`。旧任务`lz_q1l_flat_v4`仍指旧模型。
版本号从新v3继续，训练轮数将在新v4从0计数，源model800保持原编号。

## 学习方法

1. 冻结原actor、估计器、右后修正分支和原探索参数。站立和直行使用原组合控制器，训练回放也调用同一工厂，并保持原0.3秒切换状态。
2. 新增一个输出12关节修正量的侧移分支，仅纯侧移指令生效。输入为六帧观测历史及冻结估计器特征，隐藏层`[256,128]`，输出层零初始化。初始侧移使用新baseline内部冻结actor的原方向输出；左移不再套右移镜像。站立/直行仍严格继承新baseline。
3. **侧移时四条腿都可以学习；站立/直行策略参数不更新。** 侧移需要全身配合，不能继续局限在右后腿三个关节。
4. 按用户最新要求，训练和v4回放均取消左右镜像。左移和右移直接输入真实六帧观测，网络通过带符号的vy指令学习各自输出；动作、关节噪声也不交换。仍是一套以指令为条件的侧移网络，没有强制左右对称，也没有镜像数据增强。旧任务的镜像设置不变。
5. PPO只使用侧移样本更新侧移分支和它的探索参数；价值网络学习所有模式的回报。站立/直行回放不添加策略探索噪声；原环境随机化、执行延迟等保持继承。原估计器不调用更新。新v3的左后→右后模仿损失不带入侧移。
6. 打乱PPO样本时不推进0.3秒切换状态，也不让站立/直行样本稀释侧移策略梯度。基于当前物理状态的动作输出仍可能因侧移结束状态不同而不同；冻结参数不保证侧移后停车的实际受力自动恢复。

## 初始参数

|项目|新v4设置|理由|
|---|---|---|
|指令采样|站立20%、直行20%、侧移60%；侧移内部左右各半|按采样数量配平，奇数批次多出的方向轮流分配；失败重置可能造成实际经历时间不同|
|侧移速度|绝对值0.15～0.25 m/s|沿用旧v7低速阶段|
|直行速度|0.20～0.50 m/s|继承当前配置|
|转弯/斜走|本阶段不采样|限制本次任务范围|
|侧向速度奖励|1.5 × exp(-侧向误差²/0.04)|旧v7方法，原平面/转向跟踪保留|
|侧向误差惩罚|-0.5 × 绝对误差/max(指令绝对值,0.15)|旧v8方法，避免完全不移动仍只有较弱反馈|
|侧移摆腿离地不足|-0.20|沿用当前几何定义：移动且低承重的脚，离地不足才扣分|
|侧移触地滑动|-0.20|沿用当前接触点速度定义和阈值|
|侧移新增摆腿/滑动项宽限|0.30秒|指令切换后避免立即用稳态标准计分|
|高度、姿态、原承重权重|不改|保留用户接受的新baseline设置|
|学习率|固定0.0003|新侧移分支的起始值，避免旧自适应上调至0.01|
|探索标准差|初始0.20，范围0.05～0.50，动作单位|仅侧移探索，保留实际关节顺序，不镜像|
|环境/采样/PPO|4096环境、每轮100步、5轮优化×4小批次|继承项目设置|
|保存频率|50轮|最终不足50轮也保存|
|训练轮数|500|用户已明确授权，每50轮保存|

奖励表为配置权重，环境统一乘控制步长。侧移摆腿/滑动项复用现有几何公式并单独开关；没有增加侧移四脚瞬时等承重约束。现有后腿力差项仍只对直行生效，不能把它误认为侧移平衡约束。

`curriculum=False`：本次固定低速；旧代码的自动课程只扩大前后速度，并不帮助侧移。低速通过后，可在**同一个v4**上将侧移速度与`ranges.lin_vel_y`一起扩展到0.25～0.45，再续训。当前没有自动升档。

## 相对旧方法的改进与边界

- 旧方法改动全身共用网络，侧移训练可能改变直行。新方法通过独立分支保护站立/直行参数，而非依赖软惩罚保持。
- 按用户要求，取消原提案的镜像约束。左右各半保证指令分配均衡，不保证学成后的能力对称，因此必须分方向检查。
- 旧v8纯侧移采样25%，本方案60%；额外记录左/右各自速度误差、偏航、四脚力、接触和滑动，不能只看总奖励。
- 新baseline原0.3秒平滑只用于站立↔直行；当前侧移分支按指令选择，**未新增侧移进出或左右反向的时间平滑**。后续评价必须包含侧移→停、侧移→直行、左右反向，不能只分别初始化各动作。
- 侧移估计器暂时冻结；新分支能读原始六帧历史。若侧移学习受估计偏差限制，再单独评估侧移估计器，不能为此直接解冻站立/直行估计器。
- 初始学习率、样本比例和探索幅度是待验证设置，不是已证明最优的超参数。
