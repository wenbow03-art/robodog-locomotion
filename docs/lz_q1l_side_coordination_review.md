## 1. 每腿最低承重

先对每条腿的非负竖直支撑力取1秒滚动均值，再计算占四腿总支撑力的份额p_i。

`r_load = -1.0 * sum(max(0, (0.10 - p_i) / 0.10)^2)`

- 最低份额10%，达到后这一项不再扣分。没有要求四腿都达到25%。
- 窗口未满1秒不计此项；平均总支撑力低于10N时避免对不可靠比例计分。空中各脚仍受悬空超时约束。
- 单腿份额5%时该项贡献-0.25；单腿完全无承重时贡献-1.0（均为乘控制时间步之前的尺度）。

## 2. 连续未有效落地超时

每条腿记录距上一次有效支撑的时间T_i。有效支撑要求竖直力>=5N、连续两个20ms控制采样点（按40ms计）。这是采样判定，不代表观测了这40ms内的全部1ms物理接触。

`r_timeout = -0.5 * sum(min(max(0, (T_i - 0.30) / 0.30)^2, 4.0))`

- <=0.30秒不扣，超出后平方增加，每脚封顶-2.0，防止失败瞬间数值失控。
- 一帧轻碰不清零。尚未有过有效支撑的脚也计时，不能通过始终不落地避开此项。
- 计时直到有效支撑确认才清零，因此包含尚未确认的接触时间。

## 3. 有上限的正常落地奖励

替换**纯侧移时**原有 `feet_air_time` 的计算，不叠加旧公式。该项权重仍为+0.3。非侧移继续使用旧函数。

一次奖励需要：之前确实有效支撑过 → 离地 → 再次有效支撑；足端碰撞球底面相对平地的最高间隙>=1cm。首次落地、原地轻触和脚未真正抬起不给奖励。

有效摆腿时长D扣除落地确认所需的两个接触采样步：

- D<=0.06秒：0；
- 0.06<D<0.15秒：`(D-0.06)/(0.15-0.06)`；
- 0.15<=D<=0.30秒：1；
- D>0.30秒：0。

每次有效落地每脚最多贡献+0.3，继续悬空不会追加落地奖励。规则不要求四脚始终触地，允许交替摆腿。

所有奖励均由原环境统一乘控制周期0.02秒；上面的权重和例值是乘时间步之前的尺度。
