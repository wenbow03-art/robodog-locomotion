## 这次改什么

学生从指定的原始步态恢复 `model_150.pt` 初始化；另加载一份相同权重作为固定老师。完整来源为：

`HIMLoco/legged_gym/logs2/flat_lz_q1l_v2_gait/gait_from_posture500_200_20261025_113614_3235946/model_150.pt`

SHA256：`655a5022f2e1404c8f7c3dfbb670cc8235710f78e7550e72f2343e4e2c5e9747`。

每次训练采样到当前状态后，将它的六帧历史整体左右镜像，交给冻结老师。老师认为自己在控制镜像后的身体，其左后腿输出再映射回真实右后腿，成为学生右后腿的学习目标。这样目标会随当前身体和腿的状态变化，不是把真实左后腿同一时刻的动作直接复制过去，也不要求两条后腿同步摆动。

镜像涉及速度指令、角速度、重力方向、关节位置、关节速度和历史动作；左右腿互换，侧摆关节取反，大腿和小腿关节保持符号。使用关节名称定位，避免靠固定数组下标认腿。

另外九个关节参考老师在**原始状态**下的输出，施加较弱的保持约束。它们仍参与 PPO 学习，并非被锁死；共享网络参数也可能使它们发生变化。

## 损失与初始权重

令 `μ(s)` 为学生的确定性动作均值，`T(s)` 为冻结老师，`M` 为镜像变换：

```text
右后腿目标 = M(T(M(s))) 的右后腿三个输出
其他腿目标 = T(s) 的另外九个输出

总损失 = 原 PPO 损失
       + 0.10 × mean((学生右后腿输出 − 右后腿目标)²)
       + 0.02 × mean((学生其他腿输出 − 其他腿目标)²)
```

两项分别对各自的关节数、选中的样本取平均，使用网络动作单位；当前动作缩放为 `0.25 rad / 动作单位`。0.10 和 0.02 是待验证的初始值，没有宣称已找到最佳权重。新增项直接作用于策略损失，不计入环境总奖励；会单独记录原始误差、加权损失和样本数。

作用范围：零指令站立，以及直行。判定采用反归一化后的真实指令：站立三个分量绝对值均不超过 0.05；直行前进速度至少 0.10 m/s，侧移和转向分量绝对值均不超过 0.05（分别为 m/s、rad/s）。每个 PPO 小批次最多抽取 4096 个适用样本计算老师目标，以控制额外开销。

老师的权重、状态估计器全部冻结，独立于学生优化器。新增监督梯度进入学生 actor；学生状态估计器仍按原有方法学习，新增监督不直接更新它。推理时只运行学生，不需要老师，也不替换学生输出。
