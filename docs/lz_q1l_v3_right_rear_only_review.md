# 新 v3 修正版：只让右后腿学习左后腿（待审阅）

状态：代码完成、冻结验证通过、训练更新0次。用户此前停止训练的命令仍然有效；没有恢复旧实验，也没有启动新的训练。

## 实际修改范围

固定原始 gait150 baseline 的完整 actor、状态估计器与动作噪声参数。另加一个独立的三输出分支，只能给右后腿的侧摆、大腿和小腿关节增加修正量。左后腿和前两腿的九路输出直接使用冻结 baseline。

```text
冻结 baseline(当前六帧历史) ──→ 原始十二路动作
独立右后分支(冻结特征)    ──→ 右后腿三路修正

右后腿输出 = baseline 右后腿输出 + 修正量
其他三腿输出 = baseline 对应输出
```

修正分支为64维输入 → 128 → 64 → 3，ELU激活，末层权重和偏置初始化为0。因此初始十二路动作与 baseline 一致，不会先改变站姿再开始学习。

老师同样固定为原始 gait150。将当前六帧历史整体左右镜像后，查询老师的左后腿，再按关节坐标转换成右后腿目标。侧摆反号，大腿和小腿保持符号。模仿的是对应状态下的左后腿策略，不复制真实左后腿同一时刻动作，不强迫左右后腿同步摆动。

只在站立和直行启用修正与模仿。其余指令保持 baseline 输出；沿用项目现有普通推理控制器。老师只在训练中生成目标，部署不需要老师。

## 与上次的区别

上次模仿损失只针对右后腿，但 PPO 仍更新完整共享 actor、估计器和动作噪声；其他三腿仅有软保持约束。这不能保证其他三腿策略不变。

这次原策略和估计器的参数既不求梯度，也不进入优化器。优化器只包含右后修正分支和独立 critic；critic 只评价状态，不输出关节指令。估计器更新被完全跳过，包括其原先会原地归一化的原型参数。动作噪声参数全部固定。

右后腿模仿系数仍为0.10；其他三腿保持损失删除（系数0），因为九路输出已由结构保证。原始环境、奖励、PD、物理参数与站立/直行分布都不改。

由于可训练参数集合发生变化，候选入口使用新的优化器，仅作用于右后分支和 critic，不恢复旧全身 Adam 动量；baseline actor/critic/估计器权重保持来源一致，学习率使用 baseline 保存的约2.25e-5。这项初始化差异已记录，尚未实际训练。

## 保证与边界

**可以保证：同一输入历史下，前两腿和左后腿的策略输出与冻结 baseline 完全一致。**

不能保证另外三腿的实际动作轨迹或触地力永远不变。右后腿改变后，身体状态和历史动作会改变；固定 baseline 接收到不同输入，仍可能输出不同动作，物理受力也会重新分配。因此后续验收仍须同时查看前腿承重、全身左右承重和身体姿态，不能只看右后腿模仿误差。

本次不宣称右后腿或承重问题已经解决；需要用户后续明确下令训练，再做相同条件评估。

## 验证结果

1. 新环境配置与归档 baseline 完全一致。
2. 零修正初始模型的全部12路动作与 baseline 完全一致。
3. 在内存测试中临时扰动右后分支，只有右后3路发生变化，其他9路逐项完全一致；测试后恢复分支，全部参数与检查前一致。

6. 6个CPU环境回放250步，包含站立与0.35 m/s直行；每步动作均与 baseline 一致，无重置、无非有限数值。此回放检验初始等价性，不是训练后效果。

这些验证没有进行优化器更新，训练次数为0。
